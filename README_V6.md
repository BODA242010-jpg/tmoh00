# طموح TMoh V6 — دليل التثبيت

## وضع الحفظ الافتراضي
- يظل الحفظ المحلي على جهاز الطالب هو الوضع الافتراضي (localStorage و IndexedDB)، دون طلب بريد إلكتروني أو كلمة سر.
- لا تحذف بيانات الموقع أو تستخدم "Clear site data". انصح الطالب بتصدير نسخة احتياطية قبل تحديث كبير.
- لا تُنقل البيانات المحلية تلقائيًا إلى سحابة. خدمة الحساب الاختيارية تحتاج موافقة الطالب قبل ربط أي ملف.

## ماذا أضيف؟
- تحديات يومية تعتمد على النشاط الحقيقي + نقاط XP إضافية.
- رفيق طموح يتطور بإنجازات الطالب، ويمكن تسميته.
- جدول مذاكرة لسبعة أيام لا يمسح مهام المستخدم ولا ينشئ نسخًا مكررة.
- تحدي خمس دقائق من أسئلة بنك الطالب أو أسئلة معلومات عامة محددة وواضحة.
- معرض الإنجازات.
- غرفة تركيز تستخدم مؤقت طموح الأصلي، وليست عدادًا منفصلًا.
- دوري طموح الشخصي؛ المنافسة العامة بين طلاب حقيقيين تحتاج خادمًا وحسابات وموافقات.
- صفحة كتب الوزارة للصفوف الثانوية: روابط رسمية ولا تحتوي نسخ PDF غير مرخّصة.
- صفحة تسجيل بريد إلكتروني وكلمة سر اختيارية ومُعطّلة إلى أن تُضبط خدمة Supabase الحقيقية.

## نشر الملفات
1. خذ نسخة احتياطية من مستودع GitHub الحالي ومن بيانات الطالب (من إعدادات طموح).
2. ارفع محتويات الحزمة كاملة إلى **جذر المستودع** الذي يُخدّم موقع `https://boda242010-jpg.github.io/Tomh90/`، ولا ترفع مجلد الحزمة كطبقة إضافية.
3. لا تنشر ملف `rewards-ai-worker.js` على Cloudflare؛ هذا مثال مستقل وليس جزءًا من تشغيل الشات بوت.
4. لا تُحدّث أي إعدادات Cloudflare أو عامل الشات بوت. رابط المساعد واتصاله في `app.js` كما في المصدر.
5. حدّث الموقع بعد اكتمال نشر GitHub Pages (Ctrl+Shift+R).

## جعل حسابات الطلاب اختيارية بالفعل
- إنشاء مشروع Supabase (بخطة مناسبة وعدد حسابات مناسب).
- شغّل SQL في `supabase/schema.sql` داخل SQL Editor؛ افحص تفعيل RLS.
- اضبط تأكيد البريد ورابط إعادة التوجيه إلى عنوان موقع GitHub Pages.
- أدخل **Project URL** و **anon/publishable key فقط** في `cloud-config.js`، لا تضف service_role أبدًا.
- حينها الطالب سيقدر يزور صفحة "حساب اختياري" ويفتح نموذج التسجيل بإرادته، بينما يستمر الحفظ المحلي تلقائيًا للآخرين.
- لم نختبر تسجيل حسابات حقيقية أو مزامنة متعددة الأجهزة لأن المشروع والمفاتيح لم تُفعّل.

## مناهج الوزارة 2026–2027
- الكتب العامة: https://studentbooks.moe.gov.eg/Books
- كتب البكالوريا: https://ellibrary.moe.gov.eg/EgyptianBaccalaureate/
- اختَر الصف والمادة على موقع الوزارة نفسه. هذه روابط إلى مصادر رسمية، **وليست رفعًا لكافة الكتب إلى خوادم طموح**.
- محتوى وحدات المناهج لا يُولّد تلقائيًا ولا تُنسب أسئلة معلومات عامة إلى كتاب الوزارة.

## الاختبارات المطلوبة قبل الإنتاج
- افتح الصفحة على Chrome، أنشئ ملفًا محليًا، وغيّر صفحة ثم ارجع وتأكد أن البيانات ما زالت محفوظة.
- اختبر تحديات اليوم والصندوق والمسابقات وغرفة التركيز والتحديات/الجدول بدون تكرار.
- جرّب المساعد الذكي على الموقع بعد النشر، ولا تعدّل اتصال الخادم.
- تأكد من أن ملف `sw.js` تم تحميله ووصل التحديث الجديد.
- تم تشغيل فحص صياغة JavaScript؛ لم يُجر اختبار نشر إنتاج أو مزامنة Supabase حقيقية.
